# Stock return and recipe cost fixes

New sales keep each stock deduction's unit cost. Cancellation includes that
historical cost in the current stock average. It keeps the original sale cost.
Old market sales use their existing product line cost. Old recipe sales do not
have material cost snapshots; their return valuation keeps the previous rule.
No old sale or stored customer record is rewritten.

New recipe sales round the extended line cost, after multiplying by quantity.
The optional `rawUnitCostCents` field retains the unrounded unit basis. Validation
accepts old records without this field and checks new extended costs.

Current Web clients request `X-AESD-Cost-Precision: extended-v1`. They receive
precise costs. Older packaged clients receive a compatible view using their
old per-unit rounding rule. This view never changes the canonical saved cost.
Those clients need a new signed APK to display precise fractional recipe costs.
No APK is built or delivered as part of this Web release.

Regression checks cover changed purchase prices, stock returns, material
snapshots, fractional recipe costs, duplicate cancellation and legacy records.
